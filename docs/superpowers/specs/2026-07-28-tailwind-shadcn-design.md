# Tailwind + shadcn 도입과 온도 띠

- 날짜: 2026-07-28
- 상태: 디자인 방향 승인됨 (구현 계획 미작성)
- 선행: `2026-07-27-ui-contrast-light-mode-design.md` (팔레트 확정 — PR #19)
- 대상: `src/ui/**` 전반 · `src/ui/bunfig.toml`(신규) · `package.json`

## 왜 지금인가

앞선 작업(PR #19)은 대비를 고치고 라이트 모드를 붙였다. 스택은 그대로다 — 손으로 쓴 CSS
1100줄. 사용자의 원래 의도는 **"shadcn 을 쓰되 톤은 가져간다"** 였고, 대비 작업은 그
전제 조건이었다: shadcn 은 토큰 *구조*를 주지 *값*은 우리가 정한다. 이제 다크/라이트
38개 값이 확정되고 회귀 테스트로 잠겼으니, 토큰 층에 얹을 것이 생겼다.

직전에 목록의 좌측 여백을 고치면서 iframe 을 띄워 픽셀을 재고 음수 마진을 계산했다.
Tailwind 였다면 유틸리티 한 줄이었을 일이다. 이 비용이 반복된다는 게 도입의 실질 근거다.

## 전제: 행동 계층은 가져가고, 스킨은 거부한다

shadcn 을 기본값대로 쓰면 둥근 모서리 + 뉴트럴 회색 + Inter 로 수렴한다 — 이 UI 를
알아볼 수 없게 만드는 방향이다. 실제로 필요한 것은 Radix 의 **동작**이다: 포커스 트랩,
키보드 내비게이션, 스크롤 락, 접근성 트리. `DetailDrawer.tsx` 768줄이 손으로 구현한
부분이 정확히 그것이다.

**방침** — Radix primitives + Tailwind 유틸리티 + 우리 토큰. shadcn CLI 로 컴포넌트를
가져온 뒤 `radius`·뉴트럴 스케일·기본 그림자를 우리 값으로 덮는다. 가져오는 것은 구조와
동작이고, 색·모서리·간격·타이포는 전부 우리 것이다.

## 주제

로컬 데몬이 들고 있는 **한 사람과 여러 에이전트가 공유하는 작업 보드**. 화면의 단 하나의
임무 — *지금 무엇이, 누구 손에서 움직이고 있는가.* 보는 동안에도 보드는 변한다. 이것이
다른 todo 앱과 갈리는 지점이고, 디자인이 붙잡아야 할 사실이다.

## Color — 확정 팔레트 유지 + 온도를 표면까지

값은 PR #19 에서 확정·검증한 것을 그대로 쓴다. 더하는 것은 **관계**다.

```
--bg          #16110c   웜 니어블랙 (뉴트럴 검정이 아니다)
--warm        #e8a33d   에이전트 · 에리디언의 뜨거운 대기
--cool        #7ec8d8   사람 · 지구
--trace-warm  color-mix(in srgb, var(--warm) 7%, transparent)
--trace-cool  color-mix(in srgb, var(--cool) 7%, transparent)
```

지금 warm/cool 은 뱃지에만 있다. 온도가 표면까지 번지면 "누가 이 줄을 건드렸나"가 라벨을
읽기 전에 온다. `.doing-badge` 가 이미 8% 틴트를 쓰고 있어 어법이 새로 생기는 것은 아니다.

**주의** — `--trace-*` 는 색 토큰이므로 `styles.test.ts` 의 분류 상수에 등록해야 한다.
배경 위에 텍스트가 얹히는 자리이므로 명시 쌍(PAIRS)으로 검사한다.

### 니어블랙 + 밝은 액센트에 대한 방어

이 조합은 AI 디자인의 흔한 기본값이다. 그럼에도 유지하는 근거 셋:

1. 검정이 뉴트럴이 아니라 웜이다 (`#16110c` — 갈색 기운)
2. 액센트가 하나가 아니라 **의미가 다른 둘**이다 (행위자 구분이라는 기능을 진다)
3. 사용자가 이 톤을 명시적으로 지정했다 — 브리프의 말이 이긴다

## Type — 번들 mono 하나에만 투자

제약이 방향을 정한다: **오프라인 전용**(외부 리소스 금지) + **한글 콘텐츠**. 개성 있는
디스플레이 라틴 서체는 대부분 한글이 없어서, 제목에 쓰면 한영 혼용 줄이 무너진다.

```
구조 · 기계 계층  →  번들 가변 mono woff2 (한 파일, ~40KB)
사람이 쓴 텍스트  →  시스템 스택 유지 (Pretendard → -apple-system)
```

이 UI 는 구조를 전부 mono 가 진다 — 워드마크·`#N`·칩·뱃지·타임스탬프. 지금은
`ui-monospace`(맥에서 SF Mono)라 무개성이다. 거기만 바꾸면 전체 인상이 바뀐다.

*mono 가 기계, 시스템 sans 가 사람* — 주제(두 종류의 행위자)를 타이포가 그대로 말한다.
서체 선정은 구현 시점에 결정한다 (조건: 가변 woff2, 오픈 라이선스, 숫자 tabular 지원).

## Layout — 골격 유지, 상단 바를 바꾼다

3분할(보드 / todo / 노트)은 잘 작동한다. 갈아엎을 이유가 없다. 바꾸는 것은 상단 바다.

```
┌──────────────────────────────────────────────────────────────┐
│ ROCKY·TODO   ▓▓░░▒▒▓▓▓░░░░░░▒▒░░▓▓▓▓  LINK ♪   ◐  logan     │ ← 온도 띠
├────────────┬─────────────────────────────┬───────────────────┤
│  boards    │  ▸ 진행중                    │  스크래치패드      │
│            │  ░ #12 대비 리튠  claude 4m  │                   │
│  rocky-todo│  ▒ #13 라이트 모드  logan    │  메모 카드         │
│  rocky     │  ─────────────────           │                   │
│            │    #14 …                     │                   │
└────────────┴─────────────────────────────┴───────────────────┘
       ░ = 에이전트가 만진 줄 (--trace-warm)   ▒ = 사람이 만진 줄 (--trace-cool)
```

## Signature — 온도 띠 (thermal strip)

상단 바를 가로지르는 얇은 띠. **최근 활동을 시간순 온도로** 보여준다 — 앰버 구간은
에이전트가 움직인 시간, 쿨 구간은 사람이 움직인 시간, 빈 구간은 아무 일도 없던 시간.

**데이터는 이미 있다.** `GET /api/history?limit=N` 이 `{entity, entityId, actor, action, at}`
을 준다(확인함). `src/ui/lib.ts` 의 `actorTone(actor)` 이 이미 warm/cool 을 판정한다.
스키마 변경도, 새 MCP 도구도 필요 없다.

- 시간을 균등 버킷으로 묶고, 버킷마다 우세한 톤으로 칠한다
- 호버하면 그 구간의 시각과 행위자
- SSE(`/api/events`)가 오면 오른쪽 끝이 자란다
- 활동이 없으면 띠가 비어 있다 — 빈 상태도 정보다

**API 갭 하나** — `/api/history` 에 board 필터가 없다. 전역 히스토리로 시작하고(보드
전체가 오히려 "누가 이 데몬에서 일하고 있나"에 맞다), 보드별이 필요해지면 그때
`?board=` 를 더한다.

### 왜 이것이 시그니처인가

대시보드의 흔한 스파크라인은 **양**을 인코딩한다. 이 띠는 **누구를** 인코딩한다.
"너는 이 보드에 혼자가 아니다"라는, 이 제품이 다른 todo 앱과 갈리는 사실을 첫 화면에
놓는다. 그리고 지금 드로어를 열어야만 보이는 데이터를 항상 보이는 자리로 끌어올린다.

### 자기비판으로 뺀 것

숫자 매김(01/02/03), 통계 타일, 그라데이션 액센트. 셋 다 이 보드의 내용이 시퀀스도
지표도 아니라서 거짓말이 된다. 대담함은 온도 띠 한 곳에만 쓴다.

## 아이콘 — lucide-react 도입

**비용 실측** (`bun add` + `bun build` 로 확인):

| | 값 |
| --- | --- |
| 설치 무게 | 40M (개별 아이콘 모듈 4,014개) |
| 아이콘 7개 import 시 번들 기여 | 2.7KB → **gzip 1.4KB** |

트리셰이킹이 되므로 40M 은 플러그인 캐시의 **디스크** 무게이고, 사용자가 받는 페이지는
1.4KB 만 늘어난다. 앞선 논의에서 40M 을 도입 반대 근거로 쓴 것은 부정확했다.

### 그대로 두는 글리프 — 정체성

| 글리프 | 이유 |
| --- | --- |
| `LINK ♪` 의 **♪** | 로키는 음악으로 말한다. 이 UI 에서 캐릭터를 가장 많이 지고 있는 기호 |
| `ROCKY·TODO` 워드마크와 앰버 `·` | 워드마크 |
| 🪨 파비콘 | 제품 마크 |

### lucide 로 바꾸는 것 — 명료함이 이긴다

| 지금 | 바꿀 것 | 이유 |
| --- | --- | --- |
| `💬 3` | `MessageSquare` | 이모지는 색이 고정돼 warm/cool 톤을 못 받는다. OS 마다 모양도 다르다 |
| `↗` | `ArrowUpRight` | 11px 에서 글리프가 뭉갠다 |
| `→ 세션` | `ArrowRight` | 위와 같음 |
| `✓` 체크 | `Check` | 지금은 폰트 크기로 맞춘 텍스트 글리프 — 아이콘이 또렷하다 |
| `✕` 닫기 | `X` | 같음 |
| `◐ ● ○` 테마 | `Monitor` / `Moon` / `Sun` | 컨트롤은 시그니처가 아니다. `◐` 가 "시스템 따름"으로 읽히지 않는다 — 영리함보다 즉시 읽힘 |

온도 띠와 `doing` 펄스는 CSS 로 남는다 — 아이콘이 아니다.

## 알려진 함정

**`bunfig.toml` 위치** — `src/daemon.ts:63` 이 `Bun.serve` 전에
`process.chdir(join(import.meta.dir, 'ui'))` 를 실행한다. Bun 은 `bunfig.toml` 을 cwd 기준으로
찾으므로, Tailwind 플러그인 등록용 `bunfig.toml` 은 레포 루트가 아니라 **`src/ui/`** 에
놓아야 한다. `package.json` 의 `files` 에 `src` 가 있어 배포에는 함께 나간다.

**대비 회귀 테스트 유지** — `src/ui/styles.test.ts` 는 `styles.css` 를 파싱한다. 토큰이
Tailwind 의 `@theme` 블록으로 옮겨가면 파싱 대상 경로와 정규식을 함께 갱신해야 한다.
이 테스트는 버리지 않는다 — 팔레트를 잠그는 유일한 장치다.

**`DetailDrawer.tsx` 768줄** — Radix Dialog 로 옮기면서 자연스럽게 쪼개진다. 별도
리팩터링으로 다루지 않고 이 작업에 포함한다.
